A fluent API for Java's HttpURLConnection, with zero dependencies.

http-request wraps the JDK's built-in HttpURLConnection in a chainable API for GET/POST/multipart requests, headers, auth, proxies, gzip, mTLS, and more — without pulling in Apache HttpComponents or anything else.

Java 8+ · MIT · io.github.josepacelli:http-request

Installation

Available from Maven Central. No transitive production dependencies.

<dependency>
  <groupId>io.github.josepacelli</groupId>
  <artifactId>http-request</artifactId>
  <version>1.0.4</version>
</dependency>

Not using Maven? Copy the single HttpRequest.java file into your project and update the package declaration — that's the whole library.

Features

Everything is one class with inner static classes. No external dependencies, ever.

001

Fluent chaining

HttpRequest.get(url).accept("application/json").code().

002

GET, POST, PUT, DELETE, HEAD, OPTIONS, TRACE

Static factory methods for every standard HTTP method.

003

Multipart requests

Mixed text and file parts via .part(...).

004

Runtime exceptions

IOException wrapped in HttpRequestException — no checked-exception burden.

005

Basic & proxy authentication

Built-in helpers for credentials on the request or the proxy.

006

Gzip compression

Request and transparently decompress gzip-encoded responses.

007

mTLS client certificates

PKCS12 (.pfx) or separate PEM cert/key, plus trust-all overrides for testing.

008

ETag / conditional requests

ifNoneMatch() and notModified() for cache-aware clients.

009

Pluggable connection factory

Swap in a custom ConnectionFactory, e.g. to route through OkHttp.

Examples

A sample of the fluent API. Full reference in the README.

int status = HttpRequest.get("http://google.com").code();

String body = HttpRequest.get("http://google.com").body();

HttpRequest.post("http://google.com").send("name=kevin").code();

HttpRequest.get("http://google.com").basic("user", "p4ssw0rd").code();

HttpRequest request = HttpRequest.post("http://google.com");
request.part("status[body]", "Making a multipart request");
request.part("status[image]", new File("/home/kevin/Pictures/ide.png"));

FAQ

Are requests asynchronous?

No. HttpURLConnection's API is synchronous, so every method on HttpRequest is too. Call it off the main thread in UI applications — e.g. from an Android AsyncTask.

How are exceptions handled?

HttpRequest throws no checked exceptions. Low-level IOExceptions are wrapped in HttpRequestException (a RuntimeException); call getCause() to get the original IOException.

What are the dependencies?

None in production. The test suite uses Jetty 9.4 to run against a real HTTP server, but that's a test-scope dependency only — it never ships with your application.

Is this suitable for Android?

Yes — zero dependencies and a single class make it easy to drop into constrained environments where minimizing dependency weight matters.

What's the license?

MIT. Free to use, modify, and redistribute, including commercially.

Is this related to Kevin Sawicki's original http-request?

Yes — this is a modernized fork, targeting Java 8+ (up from Java 5), published to Maven Central under io.github.josepacelli, and actively maintained.
